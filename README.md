# 🌐 My Portfolio Website

## 🧾 About This Project

This is my personal portfolio website where I showcase my projects, skills, and creativity as a frontend developer. The goal of this project is to present my work in a clean, modern, and visually appealing way while ensuring a smooth user experience across all devices.

---

## 🚀 Features

* Fully responsive design
* Modern and clean UI
* Project showcase section
* Smooth layout and structure
* Video previews for projects
* Contact section

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
